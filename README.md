# Mini-Git Java

A simplified Git-like version control system implemented in Java.

## Overview

This project simulates core Git functionalities using a custom data structure built from scratch. It supports commit management, history traversal, deletion, and repository synchronization.

## Features

- Commit tracking and history traversal  
- Commit deletion (drop functionality)  
- Repository synchronization (merge two repositories)  
- Linked-list-based commit storage  
- In-place merge without creating new nodes  

## Technical Highlights

- Implemented using custom linked list structures  
- Pointer manipulation for efficient node management  
- Repository merge achieved in O(n + m) time complexity  
- Handles edge cases such as empty repositories and head updates  

## Tech Stack

- Java  
- Linked List  
- Recursion  
- Algorithm Design
